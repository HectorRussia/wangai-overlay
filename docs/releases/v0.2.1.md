# WANGAI 0.2.1 — Windows trial

- Fix the installed app opening an extra Console window whose close button also
  terminated WANGAI. Release builds now run as a Windows GUI application.
- Reset the app picker's scroll position when changing or clearing the search so
  matching games/apps are not hidden above the current viewport. Automatic
  refresh keeps the user's scroll position and search focus.
- Add packaging checks that reject Console-subsystem application binaries.

Includes Python and offline CPU Silero VAD, signed optional in-app updates and
the central AI service. Capture, F8/F9, Overlay and settings schema are unchanged.

Requirements: Windows 10/11 x64 and internet access to the configured AI service.
Windows 11 is recommended for per-app capture; older Windows 10 builds need the
existing System Output (MIXED) mode.

This trial installer is not Windows Authenticode-signed: Windows may show an
unknown-publisher warning. Verify the release checksum and download only here.
Tauri update signatures do not remove Windows publisher warnings.

Settings are preserved across upgrades. History is in-memory and clears on exit.
Render Free may need about a minute to wake; its usage statistics are ephemeral.
