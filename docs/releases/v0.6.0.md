# WANGAI 0.6.0 — Whisper Local STT

- Portable includes Whisper base Q5_1 CPU speech recognition through whisper.cpp.
- Text-only Grok translation through an independently configured gateway.
- Direct ONNX Silero VAD without PyTorch in fresh setup or frozen bundles.
- Readiness waits for both models; existing recovery retries local initialization.
- Setup/launcher scripts, pinned model downloads, feature-mode CI and handoff docs.
- Windows Portable metadata supports prerelease semantic versions.

Download `WANGAI_0.6.0_x64-portable.exe`, prepare an empty folder and run
`WANGAI.exe`. The Portable includes Whisper, its model, ONNX VAD and WebView2;
no Python, Node, Rust or provider key is needed on the user's machine.
Speech stays on the device; text is translated through the configured HTTPS
gateway. Internet is required for translation. Cloud recognition remains available
in ordinary development builds. Small and Qwen presets are out of scope.

Requires Windows x64 and an AVX2-capable CPU. Whisper base may make substantial
Thai transcription errors and does not provide cloud confidence scores.
Thai accuracy and local confidence-filter limitations are documented in the
[handoff](https://github.com/HectorRussia/wangai-overlay/blob/v0.6.0/docs/local-stt-handoff.md);
see [verification](https://github.com/HectorRussia/wangai-overlay/blob/v0.6.0/docs/local-stt-verification.md)
and the [VAD memory measurements](https://github.com/HectorRussia/wangai-overlay/blob/v0.6.0/docs/vad-onnx.md).
Live-game/real-microphone quality and clean Windows installation must be reported
separately from automated fixtures; they are not implied by a passing build.
