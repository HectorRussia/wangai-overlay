# WANGAI 0.5.1 — ปรับโครงสร้างภายในและการดูแลระบบ

รุ่นปรับโครงสร้างภายในเพื่อให้เพิ่มฟีเจอร์และดูแลระบบได้สะดวกขึ้น โดยคงพฤติกรรมการใช้งานเดิม ไม่เพิ่มฟีเจอร์หรืออ้างการเพิ่มประสิทธิภาพในรุ่นนี้

## สิ่งที่เปลี่ยน

- แยก Desktop UI, state และ transport รวมถึง application operations, audio/STT, settings และ Python worker ให้มีขอบเขตชัดเจน
- ย้าย Desktop ไปที่ `apps/desktop` และแยกโมดูล server พร้อมปรับเครื่องมือ packaging, CI และเอกสารสำหรับผู้พัฒนา
- ลบ prototype และโค้ดที่เลิกใช้ ปรับการจัดการ generated files และเพิ่มการตรวจรูปแบบโค้ดกับตัวแปรที่ไม่ได้ใช้
- Repository มีเว็บไซต์ WANGAI ที่ `apps/landing`; Landing และ Desktop ใช้ pnpm 10.32.1 และเก็บ lockfile แยกกัน เว็บไซต์ไม่ได้รวมอยู่ในแพ็กเกจ Desktop

## ความเข้ากันได้และวิธีอัปเดต

คงชื่อ commands/events, HTTP routes, payload และ worker protocol เดิม รวมถึง settings schema, installation ID, รูปแบบแพ็กเกจและการตรวจลายเซ็น ไม่มี settings migration ใหม่ในรุ่นนี้

ผู้ใช้ Portable สามารถยืนยันอัปเดตผ่านช่องอัปเดตของแอปเมื่อรุ่นนี้เผยแพร่เป็น Latest หรือดาวน์โหลด `WANGAI_0.5.1_x64-portable.exe` แล้วเตรียมในโฟลเดอร์ใหม่ สำหรับการย้ายชุด Portable ให้เก็บทั้งโฟลเดอร์รวม `Data` ซึ่งมีการตั้งค่าและข้อมูลของผู้ใช้

แพ็กเกจรวม Python worker และ WebView2 Fixed Runtime ช่อง `latest-portable.json` ใช้สำหรับ Portable ส่วน `latest.json` ยังคงชี้ตัวติดตั้งเก่า 0.2.2 ตามสัญญาเดิม

## ผลตรวจและข้อจำกัด

Local tests ผ่าน 272 รายการ รวมทั้ง frontend build และการตรวจเวอร์ชัน เจ้าของยืนยันพร้อมภาพว่าเปิดหน้าหลักบน Windows ได้ปกติ และอนุมัติ merge/tag เมื่อ 4 ตุลาคม 2026 ส่วน fixture upgrade/rollback และแพ็กเกจ signed ตัวจริงยังต้องตรวจให้ครบก่อนตั้งเป็น Latest ดู [รายงาน v0.5.1](https://github.com/HectorRussia/wangai-overlay/blob/v0.5.1/docs/releases/v0.5.1-verification.md) สำหรับผลตรวจรอบนี้แยกจากหลักฐานของรุ่นก่อน

- ใช้ Windows 11 เครื่องพัฒนาและ profile ทดสอบแยก ยังไม่ได้ตรวจบน clean Windows/VM
- การตรวจเสียงจริง, F8/F9/F10/F7, Web Companion และการอัปเดตผ่านช่องจริงที่ยังไม่เสร็จ จะไม่ถูกนับเป็นผลผ่าน
- Process Tree อาจรับเสียงไม่ได้ในบางแอป สามารถใช้ System Output ซึ่งรวมเสียงทั้งเครื่อง
- Google login บน Landing ยังเป็น mock; รุ่นนี้ไม่ได้เพิ่มระบบยืนยันตัวตนจริง
