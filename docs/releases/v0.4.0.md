# WANGAI 0.4.0 — Quiet Studio (Preview)

This is a preview, not a Stable release. Do not publish or change the normal
updater channel until artifact inspection and real update/rollback QA pass.

## หน้าตาใหม่

- Sidebar แบบยุบได้ สำหรับ Ready Room ประวัติ และการตั้งค่า
- โทน graphite–เงิน–เขียว ปุ่มแคปซูล และกระจกเฉพาะแถบควบคุม
- คำแปลล่าสุดขนาดใหญ่ พร้อมสถานะแหล่งเสียงและการเชื่อมต่อ
- Overlay ไร้กรอบ อ่านชัด ไม่มีเอฟเฟกต์หักเหหรือเบลอภาพเกม
- รองรับ reduced motion, high contrast และ keyboard focus

ใช้ CSS glass เป็นค่าเริ่มต้น ส่วน liquid-glass-react 1.1.1 ที่ตรึงไว้ยังเป็น
การทดลองใน Browser Preview จนกว่าจะผ่านเกณฑ์ Fixed WebView2 และประสิทธิภาพ

## ไม่เปลี่ยน

เสียง, AI provider, คำสั่ง Tauri, hotkeys, schema v14, installation ID และ Data
ยังใช้ระบบเดิม ประวัติเก็บในหน่วยความจำเฉพาะรอบที่เปิดโปรแกรม
หน้าจัดเตรียม Portable และ Windows titlebar ยังคงเดิม
latest.json ของรุ่นติดตั้งยังชี้ 0.2.2 ไม่ได้ใช้ Portable แทน NSIS

## สถานะการทดสอบ

ดูรายงาน `docs/liquid-glass-verification.md` ของ commit ที่สร้าง artifact นี้
Browser/automated tests ไม่ใช่หลักฐานว่า clean Windows, GPU performance,
F7–F10/click-through หรือการอัปเดต 0.3.0 → 0.4.0 ผ่านบน Windows จริงแล้ว
ใช้โฟลเดอร์ทดสอบแยก และอย่าลบหรือเขียนทับ Data ของรุ่นเดิม
