# WANGAI 0.5.0 — Mat UI (Pre-release)

รุ่นทดลองสำหรับดาวน์โหลดเอง ยังไม่ตั้งเป็น Latest และไม่เปลี่ยนช่องอัปเดตอัตโนมัติปกติ โดย 0.2.2 ยังคงเป็น Latest

## สิ่งที่เปลี่ยน

- หน้าหลักและหน้าตั้งค่าแบบ Mat พร้อมโลโก้ W และแผงเลือกแอป แหล่งเสียง ไมโครโฟน และสถานะการแปล
- Overlay คงรูป ปรับความโปร่งใสและขนาดข้อความแยกส่วน ดูตัวอย่างทันที และใช้ค่าจริงเมื่อกดบันทึก
- เลือกและจำไมโครโฟนผ่านเส้นทาง F9 เดิม พร้อมระดับเสียง และป้องกันเปลี่ยนอุปกรณ์ระหว่างกดพูด
- ปิดหน้าต่างหลักลง Tray; เริ่ม/หยุดใช้งานสลับระหว่างหน้าหลักกับ Overlay
- Settings schema 16 พร้อมสำรองและย้ายค่ารุ่นเดิม โดยรักษา hotkeys, glossary และค่าที่บันทึกไว้
- ตั้งค่า deployment สำหรับ Incoming STT เป็น Whisper Large v3 Turbo; โมเดลที่ใช้งานจริงขึ้นกับ environment ของเซิร์ฟเวอร์ การติดตั้งแอปนี้ไม่ได้เปลี่ยนเซิร์ฟเวอร์เอง

## วิธีทดลอง

ดาวน์โหลด **WANGAI_0.5.0_x64-portable.exe** ปิด WANGAI รุ่นเดิม แล้วเลือก **โฟลเดอร์ใหม่** และกด “เตรียมและเปิด WANGAI” อย่าทับชุดเดิมระหว่างทดลอง

ครั้งถัดไปเปิด **WANGAI.exe** ในโฟลเดอร์ที่เตรียมไว้ เก็บและย้ายทั้งโฟลเดอร์รวม `Data` ซึ่งเป็นการตั้งค่าและข้อมูลของผู้ใช้ History ไม่เก็บข้ามการปิดแอป

รองรับ Windows 10/11 x64 บนโฟลเดอร์ local/USB ที่เป็น NTFS รวม Python worker และ WebView2 Fixed Runtime ไว้แล้ว รุ่นนี้ไม่ถอนโปรแกรมเดิมและไม่เปลี่ยนผู้ใช้รุ่นติดตั้งเก่าเป็น Portable อัตโนมัติ

## ผลตรวจและข้อจำกัด

เจ้าของทดสอบ branch ผ่านแล้ว และ PR ผ่าน CI ทั้ง Windows/server รวม frontend, Rust Desktop/Portable, packaged worker, Python tests และ license checks ข้อมูลนี้ไม่ใช่การยืนยันว่าแพ็กเกจสุดท้ายผ่าน Windows ทุกเครื่องหรือทุกเกม

- ยังต้องตรวจการอัปเกรดจาก Portable รุ่นเก่า, clean Windows, sustained F9/ถอดไมค์, F10/Copy กับผลแปลจริง และ click-through/ลาก Overlay เหนือเกมให้ครบก่อน Stable
- ระบบตรวจอัปเดตเมื่อเปิดแอปและแจ้งเวอร์ชันใหม่ยังอยู่ ดาวน์โหลดเมื่อกดยืนยันเท่านั้น แต่ UI ตั้งค่ายังไม่มีปุ่มกดตรวจอัปเดตเอง
- Process Tree อาจรับเสียงไม่ได้ในบางแอป ใช้ System Output fallback ได้ โดยโหมดนี้รวมเสียงทั้งเครื่อง
- ช่อง `latest.json` ยังคงอ้างอิงตัวติดตั้ง 0.2.2; Pre-release นี้ยังไม่ถูกเสนอเป็นอัปเดตปกติ

ดูภาพเปรียบเทียบและรายละเอียดการทดสอบใน `docs/mat-ui-correction.md` ของ repository
