# WANGAI 0.3.0 — Windows Portable (Pre-release)

รุ่นทดลองสำหรับดาวน์โหลดเอง **ไม่ใช่ Stable และไม่ตั้งเป็น Latest** โดย 0.2.2 ยังคงเป็น Latest
รุ่นนี้ยังไม่แจกผ่านช่องอัปเดตอัตโนมัติปกติ แม้จะมีไฟล์ `latest-portable.json` แนบไว้ใน release

ดาวน์โหลด **WANGAI_0.3.0_x64-portable.exe** แล้วเลือกโฟลเดอร์และกด “เตรียมและเปิด WANGAI”
ครั้งถัดไปเปิด **WANGAI.exe** ในโฟลเดอร์ที่เตรียมไว้ ไม่ต้องเปิดไฟล์ดาวน์โหลดซ้ำ

- รวม Python 3.12, CPU Silero ONNX, Web Companion และ WebView2 Fixed Version x64
- ไม่ลงทะเบียนตัวถอนติดตั้ง ไม่สร้าง shortcut และไม่ขอ Administrator อัตโนมัติ
- เก็บ settings, installation ID และ WebView2 profile ใน `Data` ข้างตัวโปรแกรม
- ตรวจอัปเดตเมื่อเปิดแอป ดาวน์โหลดเมื่อยืนยันเท่านั้น ตรวจลายเซ็นและไฟล์ก่อนปิดแอป
- สลับโปรแกรมเป็นรายเวอร์ชัน พร้อม transaction journal และย้อนกลับเมื่อรุ่นใหม่ไม่พร้อม
- หน้าจอหลัก ระบบเสียง F8/F9, Overlay และ History แบบอยู่ในหน่วยความจำไม่เปลี่ยน

## ย้ายจาก 0.2.2

1. ปิด WANGAI รุ่นติดตั้งเดิมก่อน
2. ดาวน์โหลด Portable.exe เองครั้งแรก รุ่นติดตั้งเก่าจะไม่เปลี่ยนเป็น Portable อัตโนมัติ
3. เลือก “นำการตั้งค่าเดิมมาใช้” หรือไม่เลือกเพื่อเริ่มใหม่
4. หาก settings เดิมเสีย โปรแกรมจะแจ้งให้ตัดสินใจเอง ไม่รีเซ็ตหรือลบต้นฉบับ

ตัวติดตั้งและ settings เดิมไม่ถูกถอนหรือลบ เมื่อ Portable มี settings แล้วจะไม่นำเข้าซ้ำ
ช่อง `latest.json` ยังคงประกาศตัวติดตั้ง **0.2.2** ส่วน Portable ใช้ `latest-portable.json`

## ข้อจำกัด

- Windows 10/11 x64 บนโฟลเดอร์ local/USB ที่เป็น NTFS ไม่รองรับ UNC/network share
- **ต้องย้ายทั้งโฟลเดอร์** ไม่ใช่ WANGAI.exe ไฟล์เดียว และลบโฟลเดอร์จะลบ settings ด้วย
- ไม่เก็บ History ข้ามการปิดแอป
- แพ็กเกจใหญ่ขึ้นเพราะรวม Fixed WebView2 และ offline worker; ไม่มีการดาวน์โหลด runtime แบบลอยเวอร์ชัน
- ลายเซ็นอัปเดตไม่ใช่ Windows Authenticode certificate จึงยังอาจมีคำเตือน unknown publisher

## สิ่งที่ตรวจแล้วและสิ่งที่ยังไม่ครบ

- เจ้าของโปรเจกต์ยืนยันว่าชุด Preview จาก commit `fc369ef` ใช้งานจริงได้แล้ว
  หลังแก้สัญญา event ระหว่าง Python worker กับ Rust; เป็นผลใช้งานที่เจ้าของรายงาน ไม่ใช่ผลทดสอบ clean Windows
- ชุด Preview ดังกล่าวผ่าน CI, worker contract จาก executable จริง, การตรวจแพ็กเกจ,
  checksum, ลายเซ็นด้วยกุญแจเดิม และการตรวจ production gateway / public key
- เคยทดสอบอัปเดต 0.3.0 → 0.3.1 และ rollback ด้วยโปรแกรมจริงบนเครื่องพัฒนา
  โดยใช้ test key และ loopback fixture; ยังไม่ใช่การยืนยันการอัปเดตผ่าน production channel ทุกกรณี
- **ยังไม่ครบ:** clean Windows 10/11, Process Tree ในแอป/เกมทุกกรณี,
  การอัปเดตขณะฟังจริง, DPI/keyboard ทุกเส้นทาง และกรณี USB/พื้นที่เต็ม/ไฟดับด้วยแพ็กเกจสุดท้าย
- Process Tree อาจรับเสียงเป็น silence ในบางแอป หากจำเป็นให้เลือก System Output fallback
  โดยเข้าใจว่าจะรวมเสียงทั้งเครื่องและติดป้าย `MIXED`; ไม่ได้อ้างว่าแก้ปัญหา Process Tree แล้ว

Release workflow สร้าง Draft เท่านั้น ตรวจไฟล์ ลายเซ็น และ checksum ก่อนเผยแพร่ Pre-release เป็นขั้นแยก
CI ผ่านหรือภาพ UI ใช้งานได้ไม่ได้หมายความว่าผ่านเกณฑ์ Stable ทั้งหมด
ดูหลักฐานและข้อทดสอบค้างใน `docs/portable-verification.md` ของ repository
