# WANGAI 0.2.0 — Windows trial

- Per-user Windows x64 installer; includes Python and offline CPU Silero VAD.
- Optional, signed in-app updates through GitHub Releases.
- One manually selected listening app, F8 listening and F9 microphone reply.
- Central AI service; users do not enter provider keys.

Requirements: Windows 10/11 x64, internet access to the configured AI service.
This trial installer is not Windows Authenticode-signed: Windows may show an
unknown-publisher warning. Verify the release checksum and download only here.
Tauri update signatures verify updates; they do not remove Windows warnings.

Settings are preserved across upgrades. History is in-memory and clears on exit.
Render Free may need about a minute to wake; its usage statistics are ephemeral.
